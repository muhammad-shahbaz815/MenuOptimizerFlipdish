# Repository-Specific Rules

This directory contains Cursor rules that are specific to this individual repository. These rules represent project-specific patterns and requirements that are unique to this project.

## Purpose

- **Project Standards**: Rules that apply only to this specific repository
- **Domain Patterns**: Patterns specific to the business domain of this project
- **Local Conventions**: Repository-specific coding conventions
- **Project Requirements**: Rules that reflect the unique needs of this project

## Adding More Rules

Teams are encouraged to add more repository-specific rules as the project evolves. Consider adding rules for:

### Project-Specific Patterns

- Domain models and business logic patterns
- Repository-specific API conventions
- Local testing strategies
- Project-specific error handling

### Infrastructure Configuration

- Repository-specific AWS configurations
- Local DynamoDB patterns
- Project-specific security requirements
- Environment-specific settings

### Documentation Standards

- Project-specific documentation requirements
- Local README conventions
- Repository-specific code comments

## Usage

These rules are automatically applied when working in this repository. They can be referenced in prompts:

```
Follow the repo bootstrap-check rule for this project
```

## Maintenance

These rules are maintained within this repository and can be updated as the project evolves. They should reflect the specific needs and patterns of this project.
